# External Review Pack

This folder contains a neutral handoff for an external reviewer such as ChatGPT Pro.

Use:

1. Open `CHATGPT_PRO_REVIEW_BRIEF.md`.
2. Paste it into ChatGPT Pro, or upload it as the main context file.
3. Optionally attach the local dashboard HTML from `data/outputs/reports/experiment_dashboard.html`.

The brief is intentionally factual. It does not include our next planned methods or recommendations, so the reviewer can critique the work and propose its own conclusions.
